# 프로젝트 개요

**한자몽**은 한자 3급 자격증을 준비하면서 느낀 불편함에서 시작한 개인 프로젝트입니다.

한자를 외우고, 문제를 풀고, 틀린 내용을 다시 확인하는 과정이 여러 곳에 흩어져 있어 이를 하나의 학습 흐름으로 만들고 싶었습니다. 그래서 급수별 한자 학습과 검색, 기출 문제, 오답 노트, 즐겨찾기, 개념 학습을 한곳에 모았고, PWA를 적용해 언제 어디서든 이어서 공부할 수 있도록 구현했습니다.
